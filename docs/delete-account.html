Bounce Tower 이용자는 언제든지 계정과 서버에 저장된 데이터를 삭제할 수 있습니다. 삭제 방법은 두 가지이며, 앱 내에서 직접 처리하는 방법을 권장합니다.

방법 1. 앱에서 직접 삭제 (즉시 처리)

  1. Bounce Tower 실행
  2. 홈 화면 상단의 닉네임 칩을 누릅니다
  3. 계정 연결을 눌러 계정 화면으로 들어갑니다
  4. 아래쪽 계정 삭제를 누릅니다
  5. 경고 문구를 확인하고 정말 삭제할래요를 누르면 즉시 삭제됩니다

앱을 이미 삭제했거나 앱에서 처리가 어려운 경우 dev.hojung@gmail.com 으로 요청해 주세요. 게임 내 닉네임과 대략적인 마지막 플레이 시점을 함께 알려주시면 계정을 특정하는 데 도움이 됩니다.
