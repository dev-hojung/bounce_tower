# 스토어 등록정보 — 한국어

> Play Console → 성장 → 스토어 현황 → 기본 스토어 등록정보에 그대로 붙여 넣는다.
> 글자 수는 Play 제한 기준(앱 이름 30자 / 간단한 설명 80자 / 자세한 설명 4000자).

## 앱 이름 (30자 이내)

```
바운스 타워 : Bounce Tower
```

대안: `바운스 타워` (짧게) / `Bounce Tower` (영문만)

## 간단한 설명 (80자 이내)

```
드래그로 타워를 돌려 빈틈으로 공을 떨어뜨리는 원터치 아케이드. 오프라인에서도 즐겨요.
```

대안(69자): `타워를 돌려 빈틈을 찾아라! 한 손으로 즐기는 오로라빛 낙하 아케이드`

## 자세한 설명 (4000자 이내)

```
오로라빛 우주를 배경으로, 발광하는 공이 나선 타워를 통통 튕기며 내려갑니다.
조작은 단 하나. 화면을 드래그해 타워를 돌리고, 빈틈에 공을 맞춰 떨어뜨리세요.

■ 한 손으로, 3초 만에 시작
복잡한 튜토리얼이 없습니다. 드래그 한 번이면 규칙을 이해합니다.
짧게 끊어 즐기기 좋아 출퇴근길이나 잠깐의 틈에 딱 맞습니다.

■ 깊이 내려갈수록 뜨거워지는 긴장감
같은 색 발판은 튕겨내고, 빈틈은 통과하고, 빨간 위험 발판은 피해야 합니다.
아래로 갈수록 빈틈은 좁아지고 위험 발판은 늘어납니다. 목숨은 단 3개.

■ 5콤보, 그리고 RAGE
발판에 튕기지 않고 연속으로 통과하면 콤보가 쌓입니다.
5콤보에 도달하면 공이 불타오르며 무적 상태가 되어,
발판 종류를 가리지 않고 링 전체를 부수며 일곱 층을 관통해 강하합니다.
화면이 흔들리고 파편이 튀는 이 순간이 이 게임의 백미입니다.

■ 모으는 재미
· 공 스킨 7종 — 클래식부터 골드, 섀도우, 레인보우까지
· 트레일 이펙트 5종 — 별가루, 불꽃, 네온 리본
· 배경 테마 5종 — 오로라, 석양, 심해, 사이버펑크, 벚꽃
· 소모품 3종 — 부활권, 코인 부스터, 시작 보호막
플레이로 모은 코인으로 전부 얻을 수 있습니다.

■ 매일 돌아올 이유
· 7일 출석 사이클과 연속 보너스
· 매일 바뀌는 일일 미션, 매주 갱신되는 주간 미션
· 평생 한 번뿐인 업적 6종

■ 2주 시즌 랭킹
전체 랭킹은 명예의 전당으로 남고, 시즌 랭킹은 2주마다 새로 시작합니다.
지금 시작해도 늦지 않습니다. 시즌 목표 점수를 넘기면
그 시즌에만 얻을 수 있는 한정 스킨이 열립니다.

■ 인터넷 없이도 플레이
게임 본편은 오프라인에서 그대로 동작합니다.
랭킹과 진행도 백업에만 네트워크를 사용합니다.

■ 기기를 바꿔도 이어서
Google 또는 Apple 계정을 연결하면 재설치하거나 기기를 바꿔도
최고 기록과 모아둔 스킨이 그대로 복원됩니다.
연결은 선택 사항이며, 로그인 없이도 모든 기능을 즐길 수 있습니다.

■ 수익 모델
광고로 운영되며 유료 상품은 없습니다.
부활과 코인 2배는 원할 때만 보는 보상형 광고로 제공됩니다.
첫 세 판은 전면 광고 없이 플레이할 수 있습니다.

지금 바로, 얼마나 깊이 내려갈 수 있는지 확인해 보세요.
```
