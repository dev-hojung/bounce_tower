# 스토어 등록 자산

Play Console / App Store Connect 제출에 쓰는 자산과 문구. **모두 재생성 가능**하다.

```
store/
  listing-ko.md                  # 한국어 등록정보(앱 이름·간단한 설명·자세한 설명)
  listing-en.md                  # 영어 등록정보
  feature-graphic-1024x500.png   # Play 그래픽 이미지(필수)
  screenshots/                   # 폰 스크린샷 1080x1920 6종
```

## 재생성

```bash
cd tool/store && npm i
node shots.mjs      # 스크린샷 → store/screenshots/
node graphic.mjs    # 그래픽 이미지 → store/feature-graphic-1024x500.png
```

`shots.mjs`는 **실제 게임(`assets/www/index.html`)** 을 폰 해상도 헤드리스 크롬으로 띄워 캡처한다.
게임 코드는 건드리지 않고, 캡처용으로만 다음을 주입한다.

- 진행도가 있는 세이브(코인·스킨·최고점) — 실제 플레이로 도달 가능한 값
- 자동 조작 봇 — 이 게임은 타워를 돌려야 진행되므로, 다음 링의 빈틈으로 타워를 맞춘다
- 개발용 튜닝 패널(`#panel`)과 조작 안내 문구(`#hint`) 숨김
- 플레이 컷에서만 `RAGE_COMBO`를 올려 무적 연출을 끔(무적은 3번 컷에서 따로 보여준다)

카메라가 공을 화면 **35% 지점**에 고정하므로, 그 위치에 공이 잡힌 프레임을 골라 저장한다.

## 스크린샷 구성

| 파일 | 내용 |
|---|---|
| `01-home` | 홈 — 타워 배경, 게임 방법, 플레이 버튼 |
| `02-play` | 플레이 중 — 점수·콤보·깊이 HUD, 골드 스킨 공 |
| `03-rage` | RAGE 무적 — 링을 부수며 관통, 파편 연출 |
| `04-rank` | 랭킹 — 티어, 상위 100, 내 순위 |
| `05-shop` | 상점 — 공 스킨 탭 |
| `06-daily` | 출석·미션 |

랭킹 화면의 이름(Aiden, Yuki 등)은 **게임에 내장된 목업 데이터**다(네트워크 없이 랭킹 UI를
보여주기 위한 폴백). 실제 앱에서는 서버의 실제 기록이 표시된다.

## 제출 시 주의

- Play는 폰 스크린샷 **2~8장**이 필요하다. 6장 전부 올려도 되고 골라 써도 된다.
- 그래픽 이미지는 상단·측면이 잘릴 수 있으므로 문구를 가장자리에 두지 않았다.
- 문구를 고치면 글자 수 한도(앱 이름 30 / 간단한 설명 80 / 자세한 설명 4000)를 다시 확인할 것.
- 기능을 추가·변경하면 스크린샷과 설명문을 함께 갱신한다. 특히 **오프라인 플레이·시즌 주기·
  광고 전용 모델**은 설명문에 명시돼 있어 정책이 바뀌면 문구도 바꿔야 한다.
